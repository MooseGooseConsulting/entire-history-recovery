# One-session import prototype

The `internal/recovery` package tests a standalone wrapper around Entire CLI v0.12.2's Codex importer. It supplies one previously selected native session directly to Entire's existing parser and checkpoint writer, bypassing the current-path and age filters. It reads the session ID from the native header and preserves the original source file.

The wrapper correlates model context using matching native task start, context and completion turn IDs, including context events before or after a prompt. A legacy single-turn session without task boundaries can use one globally unambiguous model. Entire's stock Codex turn parser does not set the model. Missing, conflicting, incomplete, or uncorrelated values stay empty. This mapping has synthetic and local historical-session coverage; it still requires a broader native-format audit.

Run the synthetic fixture with `go test ./...`. It tests an old session whose original directory is gone, local checkpoint metadata and transcript readback, sanitized encrypted payloads, token usage, and duplicate-free rerun. The optional private-session test is skipped unless a local source path is explicitly supplied through `RECOVERY_TEST_CODEX_SOURCE`; never commit a real session or its path.

This is a local proof, not a production import tool. It does not map a session to a real destination, verify remote checkpoint IDs, push anything, validate server readback, or attribute work to commits. Its caller is responsible for a verified repository mapping and must explicitly choose the import's display anchor; an anchor is not proof that the session produced that commit. Upstream may choose a source-recorded resolvable turn anchor in preference to this fallback. Assess the UI's treatment of the anchor before real imports. No command-line interface is exposed yet. Entire's redaction configuration is process-global, so safe per-repository configuration must be established before multi-repo use. A real destination and its data exposure must be verified before writing or syncing.

Known segmentation gap: the upstream Codex importer treats every nonempty user-role input-text message as a separate import turn. A real inspected session contained injected environment and instruction messages in that stream. The resulting checkpoint count must not be presented as a count of human prompts. Preserve the source and investigate native event semantics before using this prototype for production imports; do not discard an input merely because it mentions a marker.
